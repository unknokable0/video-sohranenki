# KADR for Android — v0.1.0

This is a real Android application project, using the responsive KADR design bundled into a secure WebView. It does **not** contain pirated video streams or bypass geo-restrictions.

## APK via GitHub Actions

1. Open the **Actions** tab of this repository.
2. Select **KADR Android APK**.
3. Open the latest successful run for branch `cinema-prototype`.
4. Under **Artifacts**, download `KADR-v0.1.0-Android`.
5. Extract the ZIP to find `KADR-v0.1.0-debug.apk`, then open the APK on your Android phone.

Workflow URL: https://github.com/unknokable0/video-sohranenki/actions/workflows/kadr-android.yml

If the workflow shows an error or is absent, the APK is not ready; inspect the build logs. A successful build has not yet been confirmed through this connector.

## Android Studio

Open the `android/` folder as a Gradle project. Use JDK 17, Android SDK 36 and Gradle 8.13, then run `app`.

## Contents

- `app/src/main/assets/`: original prototype HTML/CSS/JS bundled locally
- `app/src/main/java/com/unknokable0/kadr/MainActivity.java`: Android WebView shell
- `app/src/main/res/drawable/ic_launcher.xml`: KADR purple app icon

Package: `com.unknokable0.kadr`, separate from SOHR.
Target Android SDK: 35, minimum: 24.

The interface and saved favorites work locally. Poster lookup from TVmaze needs internet. Movie/episode playback is a demo placeholder, **not real video**. Do not assume the named movies or their Russian audio are licensed or available in Poland.

The APK generated by this workflow is a **debug APK**, signed with a temporary debug key. New independent workflow runs may have a different signing certificate and therefore may not install as updates over earlier runs. For reliable future updates, use a persistent, privately stored production signing key and a proper release process. Never commit a private signing key to GitHub.

Source code is in the separate `cinema-prototype` branch, not SOHR's working `main` branch.
